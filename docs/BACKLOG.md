
## Break → Comeback notifications
- When user starts a break, schedule a local/push notification ~5 min later.
- Copy: gentle loss-aversion (“protect the ROI of the last session”), supportive tone.
- Must be opt-in, snoozeable, quiet-hours aware.
- A/B test: timing (3/5/7 min), message variants, emoji/no-emoji.
- Platforms: Expo Notifications (mobile), Web Push (desktop).
- Hooks into sessions API; emits analytics event on return.
